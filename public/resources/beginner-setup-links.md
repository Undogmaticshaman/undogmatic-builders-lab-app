# Beginner Setup Links

These are official starting points. Review account, privacy, and cost choices before connecting services.

- ChatGPT: https://chatgpt.com/
- VS Code: https://code.visualstudio.com/docs/introvideos/basics
- GitHub: https://docs.github.com/en/get-started/start-your-journey/hello-world
- Vercel: https://vercel.com/docs/getting-started-with-vercel
- Codex and agents: https://developers.openai.com/codex/
- Model Context Protocol: https://modelcontextprotocol.io/introduction

You do not need all six tools to begin. Start with the tool that supports your next useful action.
