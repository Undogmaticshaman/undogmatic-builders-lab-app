# Security Policy

Do not open a public issue for suspected vulnerabilities, exposed credentials, or unintended access to member data. Instead, contact the repository maintainers privately through the contact method listed on the Undogmatic Builders Lab site.

Do not include secrets, tokens, meeting links, student data, payment details, or real transcripts in a report. Provide the smallest safe reproduction possible. The project currently uses mock data and intentionally has no live member server or external service credentials.
